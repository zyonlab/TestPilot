# 任务 1：项目资产版本
- 以稳定资产名组织不可变版本，保存源运行/修订、内容哈希、基版本、依赖和操作者。
- 历史产物显式登记为候选；不自动提升旧审批或模型结论。
- 采纳使用 expectedHead 乐观并发检查；落后候选须重新基于当前版本提出。
- 快照固定已采纳版本及其传递依赖，旧内容不随项目头变化。
- 物料页提供候选登记、内容比较、依赖选择、采纳/拒绝和快照。
- 验收：跨项目拒绝、代理不能审批、并发冲突、依赖成环拒绝、旧快照不变、重启后可读、源内容不被修改。
- 边界：资产采纳不是业务需求审批、用例执行授权或测试通过。此任务的快照保存能力不等于运行已消费它。
