## 1. 五分钟理解目的

TestPilot 把衍生品交易前端的专业知识转成不同 agent 都可调用的测试能力：从物料设计用例，以机器判据发现错误，保留人的 review，并用可信实验判断下一版是否更好、更便宜、更可靠。

用户已经确认：Web 管项目、workflow、两个模型角色、物料和审核；Claude Code / Codex / PenguinHarness 宿主自己规划，另用低成本 Midscene 模型执行；Penguin UI 负责自进化评估。当前 Penguin 0.2.9 没有原生页面挂载接口，交付明确标识的独立配套扩展 UI，没有把 TestPilot 变成另一个优化器。

现有 `server/.env` 用于 Midscene。Web 初期同模型，独立 `TP_PLANNER_*` 方便以后修改。宿主继承自己的 planner，不另配。用户已授权本地真实模型/浏览器验证，不要再询问模型或密钥；环境值与凭证不要输出。项目配置优先于 env；旧运行保留冻结的模型快照。

| 设计 | 实现与理由 |
|---|---|
| 两角色显式绑定 | `packages/harness-core/src/model/`，`server/src/modelProfiles.ts` / `modelSnapshots.ts`；每运行捕获配置，独立 role proxy，不改全局 env 争用 |

| 精确领域执行 | `packages/harness-testing/src/exec/{decimal,apiOracle,session,cache}.ts`；未知与 infra 不当通过；导出共享算法与模型配置 |

| 记忆消费 | `runMemory.ts`；固定事实模板、项目/URL/材料/pageVersion 作用域、30 天 TTL、最多三条；不注入自由 markdown |
