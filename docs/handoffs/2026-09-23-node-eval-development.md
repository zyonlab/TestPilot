1. `codex/node-comparison-records`：登记时工作区版本记录；比较固定两侧产物/直接来源/运行绑定，明确未知项。人工评价独立追加，需理由和本次比较内证据，不能冒充 Gold 或自动基线。服务端和普通产物写入接口保护比较及版本记录。
2. `codex/node-comparison-ui`：评测页「节点产物对比」，全局概览、节点输入输出阅读器、版本差异、全局/节点多维评价、历史恢复与深链接。中英日及移动端可用。
3. `codex/explore-state-scenarios`：显式选择的动态计数归一化，保留原始标签与空/非空状态；同一区域内的上下文锚点；点击前复查旧选择器的标签/可见性/区域；拒绝不唯一的回退。报告缺口去重，UI 展示原始控件与区域证据。交易规则包增至 `2026-09-23.1`：Manual/Unified、Balances 计数、Market/Limit 区域约束。
4. `codex/eval-iteration-workflow`：`pnpm eval:node-quality --node all` 及节点选择器，保存开发回归清单/指纹/日志；实际下发 skill 加入状态条件、证据边界、版本比较方法。Codex/Claude 插件同步，MCP 支持比较列表、创建和读取；人工评价保持操作者入口。

前四项分支按依赖串接，后一项包含前项。操作说明与测试层次见 [节点评测与版本选择](../evaluation/node-quality.md)。
