# Explore 宿主规划与组件探索验证

分支：`codex/explore-host-planning`。本次只执行 Explore，后续模块节点断点暂停。

## 实现

Web Explore 按运行冻结的 Codex / Claude Code 宿主调用规划，输入本次领域资料、规则包、组件编号与页面观察。规则包不再使宿主规划被跳过。输出业务归属假设、优先顺序、理由、预期观察和风险；模型不能编造选择器。四次规划调用都有不可变回执，并与探索报告关联。

补采自定义 div/span，操作前验证标签、区域、遮挡。候选筛选剔除被浮层遮挡的背景控件，避免提前消耗目标；无候选时尝试 Escape，然后历史回退。已登记探索禁用通用表单/回车探针。内置规则包升级到 `2026-09-24.2`，允许 Tab 和面板的 UI 操作，禁止交易提交与确认。

报告 UI 展示每批业务规划、预期、操作后变化和缺口；状态变化不等于业务断言通过，也不证明因果关系。
